## Сессия 3 — 2026-10-09: импорт героев TitansDB, расчёт статов, сверка

### Сделано
- Коммит результатов сессий 1–2 (`84705a1`).
- **`src/data/titansdb.ts`**: `parseTitansDb` (TAB-поля, блок через `|` ищется динамически, BOM, сломанные строки → ошибки с номером) и `matchTitansDb` → `HeroInstance` + отчёт импорта. Имена — без учёта регистра и вида апострофа; камень — по стихии и величине; навык — имя → id иконки fankit (`S_scythemaster`) → описание (`Mana Shield` → линейка `Magic Shield`). Формат описан в SCHEMA → «Экспорт TitansDB».
- **Открытие:** TitansDB пишет описание **высшей** ступени навыка, а реальная ступень зависит от стихии героя: безымянная колонка 4 в SKILLS — порог стихии (A12, A22). Поэтому `HeroInstance` хранит линейку навыка, ступень считает движок.
- **`src/engine/stats.ts`** — `calcStats(hero, data)` → ATK, DEF, HP, CRIT, CRIT_DMG, EVA, THREAT, ELEMENT + разбивка (база, вклад каждого предмета, %, действующие навыки со ступенью). Формулы Combat Compendium; правила, выведенные сверкой: камень/дух добавляют только существующие статы предмета, духи складываются, «stats with <тип>» не усиливает DEF, встроенный камень даёт только стихию, итог — отбрасывание дробной части, Ninja (+20/+20) как в HEROES. Неподтверждённые параметры собраны в `StatModel` (`constants.ts`).
- **Контрольный пример компендиума** (Geomancer Gong): 16307 на числах статьи, 15797 на текущих данных — `src/engine/stats.test.ts`.
- **База по уровню (A8):** обратный счёт + МНК, форма выбрана по leave-one-out: база₁·(1 + k·(L−1)) + c·(L−1). Для импортированных героев база берётся из эталона экспорта (`referenceBase`), пока уровень не изменился; перекрёстная проверка на паре Geomancer 26 — ATK +1,5%, DEF −0,1%, HP +0,7%.
- **Midas' Tragedy (A15):** Amulet (T10) → +25%, Ring (T15) → +50%; общее правило в `build.ts` (i-й по тиру предмет → i-я строка SKILLS). Сверка по Брю слабо подтверждает +25% у Amulet.
- **Хранение героев** (`src/data/heroStore.ts`): IndexedDB (`heroes`), экспорт/импорт JSON (`st-app/heroes`, проверка схемой), повторный импорт .txt обновляет героев по имени и классу, а не дублирует.
- **Страница «Герои»** (`src/routes/heroes.tsx`, ссылка в шапке): загрузка .txt/.json (выбор файла, перетаскивание, вставка текста), отчёт импорта, карточки героев (слоты с иконками, навыки со ступенью, расчёт / экспорт / модель без эталона), экспорт JSON, удаление.

## Чего не хватает в таблице

Критично для движка:
1. **Множители качества** (Normal/Superior/Flawless/Epic/Legendary) для статов предметов, а также для камней и духов (A7).
2. **Прирост статов героя по уровням.** HERO LEVELS содержит только XP и максимальный тир, HEROES — одно значение на класс (A8).
3. **Пороги защиты квестов** (DEF → 50/70/75% снижения урона) — только на stcentral-hub, лицензия ND (A10). Для Lost City of Gold нет нигде. *Сессия 2: загружаются в рантайме.*
4. **Формулы боя:** урон героя по монстру, снижение урона от DEF между порогами, вероятность и частота AoE, выбор цели по Threat, работа EVA/CRIT/Mana Shield, лимит раундов, условие провала.
5. **Механика стихийного барьера:** порог или пропорция, как суммируется стихия отряда, вклад чемпиона и стихии героя, «Any» у Spellblade (A9).
6. **Эффект Elemental Affinity** и условие навыка духа «+» (A5, A6).
7. **Как статы зачарования складываются со статами предмета** (полностью ли, масштабируются ли качеством камня или предмета).
8. Боевые апгрейды предмета — Starforged (`+25% Base ATK, DEF and HP`, `DEF +20`) и Transcendence (`ATK +2`, `+10% Base …`). Данные есть, но нужно знать, какие апгрейды у конкретного предмета пользователя → это поля инвентаря, а не таблицы.

Менее критично:
9. Типы `Dual Wield`, `Familiar`, `Aurasong` не встречаются ни в одном слоте классов. Возможно, это экипировка чемпионов или особые правила.
10. `Built-In Spirit = Mundra's Spirit` — такого духа нет в ENCHANTMENTS и SKILLS.
11. Чемпионы `Aang`, `Sokka` есть в SKILLS (`Classes`), но отсутствуют в CHAMPIONS.
12. Нет заголовков у колонок-иконок (ресурсы в BLUEPRINTS, стихии в ENCHANTMENTS, колонка 4 в SKILLS) — восстановлены выводом (A2, A3, A12).
13. Нет ID линеек навыков. Линейка определяется по соседним строкам и росту Tier.
14. Нет идентификаторов для картинок (slug для playshoptitans.com / stcentral-hub fankit) — *решено в сессии 2: `imageMap.json`, см. SCHEMA → «Внешние id».*
15. Названия боссов и саб-локаций — только на stcentral-hub.
