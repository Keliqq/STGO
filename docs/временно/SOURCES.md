# Базовые статы героев по уровням — источники

## Что в файлах
- `levelstats.json` — исходный файл без изменений: `{ "<Класс>": { "hp": [50 чисел], "atk": [...], "def": [...] } }`, индекс 0 = уровень 1.
- `levelstats.csv` — то же в таблице: `class,level,hp,atk,def` (42 класса × 50 уровней = 2100 строк).
- Классы: 21 базовый + 21 промоушен (имена как в игре, английские).
- Это базовые статы героя без экипировки, семян и навыков.

## Откуда
- Файл: https://stcalc.com/data/levelstats.json — открытый файл данных сайта stcalc.com («Shop Titans Hero Simulator»).
  Скачан 12.10.2026.
- Автор сайта и сборки данных: **tadzhx** (Discord), сервер сайта: https://discord.gg/hUPw4hEKBh.
- Как найден: в исходниках сайта (`App.jsx`) приложение загружает `/data/levelstats.json`; в комментарии `calc.js`
  автор пишет, что файл содержит «собственные значения игры по уровням».
- Игровые данные принадлежат Kabam Games, Inc. (Shop Titans). stcalc.com — неофициальный фанатский инструмент.

## Проверка
- Уровень 1 совпадает с листом HEROES официальной таблицы данных
  (https://docs.google.com/spreadsheets/d/1WLa7X8h3O0-aGKxeAlCL7bnN8-FhGd3t7pz2RCzSg8c):
  Soldier HP 30 / ATK 10 / DEF 15.
- Уровни 2–50 в этой таблице отсутствуют (лист HERO LEVELS содержит только опыт и максимальный тир предметов),
  поэтому независимо не проверены. Сверка — по экспорту TitansDB своих героев (fixtures/heroes.txt).
